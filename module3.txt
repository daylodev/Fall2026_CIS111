2. Django
https://www.djangoproject.com/

Django is a commonly used web framework. I believe this is an essential tool for python
web developers. It's many scalable features are designed to handle versatile tasks for
sites, scripting, and data with secure processes. This may become a powerful addition
I'd rely on in my future web development projects.

4. Tenacity
https://linkprotect.cudasvc.com/url?a=https%3a%2f%2fpypi.org%2fproject%2ftenacity%2f%23description&c=E,1,hpL5brGjQjbl_B0v1RWzu08Ad26euKsPLAp7j9vLLkQMkgXwwFVzZkL31OfSjR-skqgebVzvJgOzM4RmqWxK5vMrjilAk4jIbE0l2taZQg,,&typo=1

Tenacity is an automatic system to continuously attempt running a program. I think
it would be useful for accessing APIs, however, in the documentation it states that
this tool is not API compatible. It can be used for functions and specified to run 
a certain amount of times, or while meeting a set of conditions.
